# Courier Tracking System
## About the Project
A python-based Courier Tracking System that helps users book parcels and track their delivery status.

## Features
- Book a parcel
- Generate unique tracking IDs
- Update parcel delivery status
- Track parcels
- Search by receiver name
- Maintain delivery history

## Technologies Used
- Python
- Dictionaries
- Lists
- Functions
